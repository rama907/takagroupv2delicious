# Taka Group V2 Delicious

A web-based management application developed using PHP, TypeScript, JavaScript, CSS, and MySQL.

The project is organized into multiple application components and supporting modules for managing web-based business operations.

## 🛠️ Technologies

- PHP
- TypeScript
- JavaScript
- CSS
- MySQL
- Apache / `.htaccess`
